# 龍体文字Web V3.13

V3.12を基礎に、Windowsで共有画面が利用できない場合でも扱いやすい共有方法を追加しました。

## V3.13の変更
- 共有画面に「端末で共有」「個別保存」「ZIP保存」を追加。
- Windowsでは個別保存またはZIP保存を推奨する案内を表示。
- 画像・CSV・Wordから1つ以上を選択し、選択したファイルだけを保存できます。
- ZIP保存では選択した複数データを1ファイルにまとめます。
- 端末共有に非対応のブラウザでは、保存方法を案内して画面が止まらないようにしました。
- 画面右下に Version 3.13 を表示。
- 龍体文字フォントを assets/fonts/pkryutaib3-Regular.otf に同梱。
- Service WorkerキャッシュをV3.13へ更新。
