# 龍体文字 Web V3 試作品

Unity版の「1ページずつ進むウィザード形式」を残しつつ、スマホ・タブレット向けにUIを再設計した試作品です。

## 今回のUI方針
- 1画面1目的
- アイコン + 短い見出し + 短い説明
- ダークグレー基調のシンプルな外観
- 選択肢はカード / セグメント / スイッチで表示
- スマホでは1列、タブレット・PCでは複数列へ自動変更
- 画面上部に進捗バー
- 「戻る」「次へ」は画面下部で統一
- 履歴はタブレットでは2ペイン、スマホでは一覧→詳細へ切替

## 開き方
まずUI確認だけなら `index.html` をダブルクリックしてブラウザで開けます。
IndexedDB・PWAを安定して確認する場合はGitHub Pages等のHTTP/HTTPS環境で開いてください。

## 龍体文字フォント
元のUnityプロジェクトで使用している `pkryutaib3-Regular.otf` は、このZIPには含めていません。
以下に自分でコピーしてください。

`assets/fonts/pkryutaib3-Regular.otf`

フォルダがない場合は `assets/fonts` を作成してください。

## 主な機能
- 7ステップの作成ウィザード
- 項目名
- 文字数 / カラー / 作成モード
- 1〜20文字の文字選択
- 10 / 12 / 24色
- 色選択
- 直線 / 右回り / 左回り
- 完成プレビュー
- IndexedDBローカル保存
- 履歴
- 再編集
- 複製
- お気に入り
- PNG出力

## v3.1 キャッシュ更新について
GitHub Pagesで旧バージョンが表示され続ける問題を軽減するため、`sw.js` を更新しています。
新しいService Workerが有効になると旧キャッシュを削除し、ページ本体はネットワーク上の最新版を優先して取得します。
初回だけ旧Service Workerが残っている場合は、ブラウザのサイトデータ削除またはService WorkerのUnregister後に再読み込みしてください。
