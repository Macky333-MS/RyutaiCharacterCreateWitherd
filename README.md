# 龍体文字 Web V3 試作品

Unity版の「1ページずつ進むウィザード形式」を残しつつ、スマホ・タブレット向けにUIを再設計した試作品です。

## 今回のUI方針
- 1画面1目的
- アイコン + 短い見出し + 短い説明
- ダークグレー基調のシンプルな外観
- 選択肢はカード / セグメント / スイッチで表示
- スマホでは1列、タブレット・PCでは複数列へ自動変更
- 画面上部に進捗バー
- 「戻る」「次へ」は画面下部で統一
- 履歴はタブレットでは2ペイン、スマホでは一覧→詳細へ切替

## 開き方
まずUI確認だけなら `index.html` をダブルクリックしてブラウザで開けます。
IndexedDB・PWAを安定して確認する場合はGitHub Pages等のHTTP/HTTPS環境で開いてください。

## 龍体文字フォント
`assets/fonts/pkryutaib3-Regular.otf` を同梱しています。追加のコピー作業は不要です。

## 主な機能
- 7ステップの作成ウィザード
- 項目名
- 文字数 / カラー / 作成モード
- 1〜20文字の文字選択
- 10 / 12 / 24色
- 色選択
- 直線 / 右回り / 左回り
- 完成プレビュー
- IndexedDBローカル保存
- 履歴
- 再編集
- 複製
- お気に入り
- PNG出力

## v3.1 キャッシュ更新について
GitHub Pagesで旧バージョンが表示され続ける問題を軽減するため、`sw.js` を更新しています。
新しいService Workerが有効になると旧キャッシュを削除し、ページ本体はネットワーク上の最新版を優先して取得します。
初回だけ旧Service Workerが残っている場合は、ブラウザのサイトデータ削除またはService WorkerのUnregister後に再読み込みしてください。

## V3.2 変更点
- カラーOFF時はSTEP 5（色数）・STEP 6（色選択）を自動スキップします。
- 作成モードを切り替えても文字数は変更されません。
- 通常モード：指定文字数分の文字を先に選択 → カラーONなら色設定 → 形状へ進みます。
- 1文字ずつモード：カラーONでは「文字1 → 色1 → 文字2 → 色2…」を自動で行き来します。
- 1文字ずつモード＋カラーOFFでは、色設定を挟まず文字を順番に選び、最後に形状へ進みます。
- STEP 6 に、色を設定する対象文字のセレクターを追加しました。


## V3.3 変更点
- STEP 3 / 4 の文字選択ダイアログを50音表レイアウトに変更しました。
- 50音表では各マスに「通常のひらがな」と「龍体文字」を併記し、形と読みを関連付けやすくしています。
- STEP 3 / 4 の選択済み龍体文字は、カラー設定に関係なく白色で表示します。
- 「仮名表示」を有効にすると、選択済み龍体文字の上に対応するひらがなを表示します。
- 仮名表示をONにする前に、龍体文字そのものの形を覚える用途では非表示を推奨する確認メッセージを表示します。
- 龍体文字フォント `pkryutaib3-Regular.otf` を `assets/fonts/` に同梱しました。


## V3.4 変更点
- STEP 3/4 の文字選択表から、可視のひらがな・行名・段名を削除しました。
- 説明文は「50音表と対応付けています。」に変更しました。
- 文字表では龍体文字のみを表示します。
- 表の左側に横一列、下側に縦一列をハイライトする操作ボタンを追加しました。
- ハイライト操作ボタンはタップに加えて、指またはペンでなぞる操作にも対応しています。
- 行と列を同時に指定した交点は、より強くハイライトされます。
- `assets/fonts/pkryutaib3-Regular.otf` を同梱しています。
