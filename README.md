# 龍体文字Web V3.12

V3.11を基礎に共有機能を追加した版です。

## V3.12の変更
- 保存データの詳細画面に「共有」ボタンを追加。
- 共有する形式を「画像 / CSV / Word」から1つ以上選択できます。
- 対応ブラウザではWeb Share APIを使い、スマホやPCのネイティブ共有メニューを開きます。LINE等が共有先としてOSに登録されている場合は、共有メニューから選択できます。
- ブラウザがファイル共有に対応していない場合は、選択したファイルをダウンロードする代替動作になります。
- 画面右下に `Version 3.12` を表示します。
- `assets/fonts/pkryutaib3-Regular.otf` を同梱しています。
- Service WorkerキャッシュをV3.12へ更新しました。

## 注意
共有先に表示されるアプリはOS・ブラウザ・端末側の対応状況に依存します。WebページからLINEなど特定アプリを強制的に指定することはできません。
