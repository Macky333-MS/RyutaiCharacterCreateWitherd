# 龍体文字 Web V3.9

V3.8を基礎に、以下を修正・追加しています。

- STEP7の「プレビューを見る」が開かない不具合を修正（配置計算 `getPositions` を復元）
- 履歴の「画像保存」が動作しない不具合を修正
- PNGはアプリと同じ濃色背景で保存し、白文字も見えるように調整
- 保存データ詳細に、各文字の「対応するひらがな」と「HEXコード」を表で表示
- CSV保存を追加（1行目=ひらがな、2行目=HEX、各文字を1列ずつ配置）
- Word保存を追加（Wordで開ける `.doc` 形式、色付き龍体文字と対応表を出力）
- `assets/fonts/pkryutaib3-Regular.otf` を同梱

## Word保存について

Word出力は、編集可能な文字として保存するため `.doc`（Wordで開けるHTML形式）を使用しています。龍体文字を同じ字形で表示するには、Wordを開く端末に `pkryutaib3-Regular.otf` をフォントとしてインストールしてください。

## CSVの例

1文字目が「う」・`#001133`、2文字目が「あ」・`#FF0000` の場合：

```csv
う,あ
#001133,#FF0000
```
