# 龍体文字作成 Web Wizard Prototype

Unity版で使っていた「1/7〜7/7」の画面設計を残しつつ、内部では1つのWebページとして動く試作品です。

## 主な実装

- 7ステップの龍体文字作成UI
- Unity版に近い黒背景・大きなボタン・戻る/次へ配置
- 1〜20文字
- 10色 / 12色 / 24色
- 直線 / 右回り / 左回り
- 完成前プレビュー
- 完成時にIndexedDBへ自動履歴保存
- 履歴一覧 + 詳細の2ペイン表示
- 再編集 / 複製 / お気に入り / 削除 / PNG画像保存
- スマホでは履歴を「一覧→詳細」に自動切替
- PWA用 manifest / Service Worker

## 龍体文字フォント

システム上の都合でフォントファイル自体はこのZIPに含めていません。

Unityプロジェクトにある `pkryutaib3-Regular.otf` を、ご自身のPC上で次の場所へコピーしてください。

```
RyutaiWebWizardPrototype/
└─ assets/
   └─ fonts/
      └─ pkryutaib3-Regular.otf
```

配置後、ブラウザを再読み込みすると龍体文字フォントが適用されます。

## 開き方

### 見た目だけ確認
`index.html` をダブルクリックしてブラウザで開けます。

### ローカル保存 / PWAまで安定して確認
GitHub Pagesまたは VS Code + Live Server を推奨します。

## 注意

- これはUI/操作フロー確認用の試作品です。
- Unity版の「共鳴練習」「仮名表示」の詳細処理は現時点では説明ダイアログだけです。
- 右回り/左回りの配置はWeb版の仮アルゴリズムです。Unity版と完全一致させる場合は元の配置ロジックを移植してください。
