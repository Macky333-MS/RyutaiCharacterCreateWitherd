# 龍体文字Web V3.10

V3.9をベースに次を修正しました。

- STEP7プレビュー背景を中間グレーへ変更し、黒文字・白文字の両方を見やすくしました。
- PNG書き出し時の背景も同じ中間グレーに変更しました。
- 完成時の「保存」で画面が止まる場合に備え、IndexedDB初期化・保存処理を堅牢化しました。
- 保存中はボタンに「保存中…」を表示し、二重押下を防止します。
- 保存成功時は完了ダイアログ、失敗時は原因を示すエラーダイアログを必ず表示します。
- ID生成処理も対応ブラウザ差で停止しないようフォールバックを追加しました。
- Service Workerキャッシュ名を V3.10 に更新しています。
- `assets/fonts/pkryutaib3-Regular.otf` を同梱しています。
